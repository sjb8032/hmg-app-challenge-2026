## 제출물

- 필수: 접수양식(기획서) DOCX. 참가자 전원이 개인정보 동의서에 각자 서명
- 가산점: 시연 영상, GitHub 저장소(소스 + APK)
- 받는 주소: appdevchallenge@hyundai-partners.com
- 메일 제목: `[차량용 앱 개발 공모전] 팀명(개인은 성명)_대표자명`, 팀원 전원 CC
- 수정 제출: 제목 앞에 `[수정제출]`, 전체 자료와 동의서 재첨부, 마지막 제출본이 최종본

## 이 저장소에 해당하는 규칙

- APK는 `apk/` 폴더에 `팀명_앱이름_release.apk`, 실행 가능한 release 빌드
- 용량을 넘으면 GitHub Releases에 올리고 Release 페이지 주소를 제출
- README에 앱 이름·한 줄 소개, 실행 방법, 테스트 환경·필요 설정, APK 위치를 적음
- 비공개 저장소는 주최측이 공지하는 심사용 계정을 Collaborator로 초대해야 함. Organization 저장소면 Read 권한만 줄 수 있음. 마감 전에 접근되는지 확인
- 접수양식, 동의서 등 개인정보가 든 문서는 저장소에 올리지 않음
